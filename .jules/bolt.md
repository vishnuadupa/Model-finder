## 2024-05-24 - Do not remove unrequested functions\n**Learning:** Always stick exactly to the scope of requested dead code removal to avoid regressions. Deleting sibling functions that were not explicitly flagged as dead code can cause subtle breakages.\n**Action:** When removing dead code, verify that ONLY the target functions/lines are modified in the diff. Never guess that a sibling function is unused without explicit user confirmation.
